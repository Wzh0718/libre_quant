# 我的盘：模拟盘 / 实际盘 / 未来 3 天预案（docs/14）

> **日期**：2026-09-15 · **代码**：`libre_quant/accounts.py` · `store`（account/account_trade）
> · API：`/api/plans` `/api/accounts` `/api/accounts/{id}/trade`
> `/api/accounts/{id}/outlook` · 前端「我的盘」页
> 起因：用户要求「选择股票 → 选择方案 → 定投逻辑 → 开始开盘，以及实际盘；
> 输入今天买入的价格与时间后继续核算；策略组还要给至少未来 3 天的趋势」。

## 一、产品定位：只做场内

按用户要求**移除场外基金概念**：`/api/ingest` 拒绝无场内价格的代码
（提示「本项目只做场内股票/ETF」），账户只能建在有交易所行情的标的上。
（docs/13 的场外基金通路仍在代码里作为库能力，但产品面不再提供。）

## 二、两个盘

| 类型 | 数据来源 | 用途 |
|---|---|---|
| **模拟盘（paper）** | 方案 + 参数**推演**（读取时按库内价格重算，天然幂等） | 「如果我按这个方案做」 |
| **实际盘（real）** | 用户录入真实成交（日期/价格/数量） | 「我实际做得怎么样」 |

**方案注册表**（`PLANS`，全部来自已实证的规则，docs/09/12）：

| plan | 名称 | 逻辑 |
|---|---|---|
| `naive` | 朴素日投 | 每交易日固定金额买入 |
| `gate` | 闸门日投 | 溢价 > 阈值暂停，钱攒着，回落当日连本带额补投 |
| `deep_value` | 折价重投 | 折价全投、1~2% 投一半、2~5% 与 >5% 暂停 |
| `monthly` | 月度定投 | 每月首个交易日按月度金额（=日额×20）买入 |

参数：`daily`（每日金额）、`gate`（溢价阈值，默认 5%）。

**估值口径（关键）**：模拟盘**待投现金计入账户资产**——
闸门暂停期间钱还在你账上，只是没买成份额。

```
市值 = 份额 × 最新价 + 待投现金
投入 = 计划现金流累计（暂停日也算投出，因为钱已从工资划出）
盈亏 = 市值 − 投入 ;  XIRR 现金流 = 每个计划投入日
```
实际盘：投入 = 买入流水累计，无现金概念（未投入的钱不在本系统视野内）。

## 三、未来 3 天预案（不是价格预测）

**先说边界**：本项目已用大量实验证明**价格方向不可预测**——
趋势择时（MA/唐奇安/双均线）净择时全负（docs/04/05），5 月线是纯保费（docs/08），
投放层优化 ≤±0.04pp（docs/12）。所以「未来 3 天趋势」给的是三样**可验证**的东西：

1. **执行预案**：未来 3 个交易日每天的动作（买入/暂停）+ **触发条件**
   （例：「溢价回落到 ≤5% 才恢复买入（当前 +10.32%）」）；
2. **波动率区间**：用 60 日已实现波动率推 ±1σ 带，随天数按 **√t** 张开
   （例：22.5% 年化 → 3 日 ±2.3%）；
3. **实证分布**：当前溢价所在档的历史前向收益
   （例：>5% 档 316 天，前向 1 日 −0.15%、5 日 −0.51%）——
   这是**统计规律**，不是承诺。

预案里明确写入免责声明，避免被误读成预测。

## 五、局限

1. **交易日历只跳周末**，法定节假日未建模（预案日期需人工留意）。
2. 实际盘的**未投入现金不在账内**（只核算已买部分），因此实际盘 XIRR
   与模拟盘不完全可比。
3. 模拟盘推演假设「收盘价成交」，未含盘中滑点；佣金按万0.5/最低0.1元。
4. 预案的波动率区间是**统计带**，不含趋势/方向信息（这是刻意的，见 §三）。
