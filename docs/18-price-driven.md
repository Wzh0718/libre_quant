## 二、把价格信号用满：单边无效，双侧最优

docs/17 已证：**本 ETF 价格的 7 日涨跌**是唯一"相关性尚可 + 完全单调"的信号
（跌 >5% → 前向 5 日 +1.61%；涨 >5% → −0.12%）。据此把两侧都做成规则：

| 规则（纯价格驱动，200 元/日基准） | 投入 | 期末 | XIRR | 回撤 |
|---|---:|---:|---:|---:|
| ① 纯定投（基准） | 543,600 | 1,760,167 | 19.78% | 30.2% |
| ② 只加码：跌 >5% 加投 3 倍 | 639,000 | 2,058,111 | 19.89% | 28.4% |
| ③ 只减码：涨 >5% 暂停 | 497,200 | 1,637,332 | 19.80% | 30.2% |
| ④ 只减码：涨 >5% 减半 | 520,400 | 1,698,750 | 19.79% | 30.2% |
| ⑤ 双侧：跌>5%加 3 倍 + 涨>5% 暂停 | 592,600 | 1,935,275 | **19.91%** | **28.3%** |
| ⑥ 双侧：跌>5%加 3 倍 + 涨>5% 减半 | 615,800 | 1,996,693 | 19.90% | **28.3%** |
| ⑦ **双侧：跌>3%加 2 倍 + 涨>3% 减半** | 624,800 | 2,013,585 | **19.93%** | 28.9% |

**结论**：单边（③④）几乎无效；**两侧同时用**才把 XIRR 抬到 19.90~19.93%
（+0.12~0.15pp）并把回撤压到 28.3~28.9%（−1.3~1.9pp）。
这是迄今所有测试规则里的最佳组合。

## 三、今日指令：两条驱动合成一个动作

看板顶部现在给出**唯一的今日指令**（避免"看五个数字自己拍"）：

```
今日动作   暂停买入 0 元
场内价格   1.624   7 日 −2.40%   当前溢价 +10.32%
规则命中   [价格正常] [溢价闸门]
待投现金   200 元
```

合成优先级（写在代码里，可审计）：

1. **未设置参数** → 只陈述状态，不给金额（不发明数字）；
2. **溢价闸门命中** → 0 元（闸门优先，价格规则不覆盖）；
3. **价格加码命中** → `每日 × (1 + 加码倍数)`；
4. **价格减码命中** → `每日 × 冲高系数`（0 = 暂停，0.5 = 减半）；
5. 否则 → 按每日金额买入。

推理链同时说明命中了哪条规则、依据什么数字、历史上该档的前向收益。

## 四、参数（都在「我的定投参数」卡，默认关闭）

| 参数 | 含义 | 默认 |
|---|---|---:|
| 每日金额 | 基础定投额 | 未设置 |
| 溢价闸门 % | 溢价超过则暂停 | 5 |
| 回撤加码：跌超 % | 7 日跌幅 ≥ 此值 → 加投 | 0（关） |
| 加码倍数 | 加投 = 每日 × 倍数 | 0（关） |
| 冲高减码：涨超 % | 7 日涨幅 ≥ 此值 → 减码 | 0（关） |
| 冲高系数 | 当日金额 × 系数 | 1（关） |
| 趋势闸门 pp | 溢价 7 日上升超此值 → 暂停 | 0（关） |

## 五、诚实边界（必须说）

1. **多重检验**：docs/12、15、16、17、18 合计已试二十余条规则，
   +0.15pp 的优势需 **walk-forward** 复核（Phase 4）后才宜放大仓位。
2. **执行依赖资金弹性**：加码需要"跌时还有钱"，减码意味着"涨时少投"——
   两者都要求你的现金流能随规则伸缩；做不到就退化为纯定投。
3. **止损缺失**：本方案没有止损，靠的是"越跌越买 + 长期上行"的前提；
   若标的进入长期下行（如 2000-2002 纳指），加码会持续放大亏损。
4. 仍按**收盘价**成交建模，未含盘中滑点。
