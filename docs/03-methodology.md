# 方法论：因子验证的「筛子」

> 这套流程是本次研究最有价值的产出 —— 比任何具体因子都重要。

## 为什么需要它

用户的原始诉求是「因素太少了，要加因素」。但真正的问题不是**少**，是**没有淘汰机制**。

标的的现实约束：

| 约束 | 数值 |
|---|---|
| 标的数 | **1**（单只 ETF） |
| 成分股 | 43 只（全量 50，剔除 7 只占位） |
| 历史 | 2019-12 至今 ≈ **6 年** |
| 日线样本 | ≈ **1500 根** |

> **在这个样本上精调参数，几乎必然过拟合。这不是保守，是数学。**

所以顺序不能是「加因素 → 回测 → 调参」，必须是：

```
建记录 → 建归因 → 单因子检验 → 只在证据充分时改
```

**没有第一步，调的每个参数都是猜。**

---

## 核心工具：gap / intra 分离

### 问题

对任何"领先指标"（隔夜美股、宏观数据、新闻），直接算
`corr(领先指标, 标的收益)` 是**错的**，会得到虚高的相关性。

原因：跨市场/跨时段的信息，在标的**开盘集合竞价**时就已经反映进价格了。

### 正确做法

把标的收益拆成两段：

```
gap[T]   = A_open[T]  / A_close[T-1] - 1     ← 信息传导到开盘
intra[T] = A_close[T] / A_open[T]   - 1      ← 开盘后是否延续
```

| 量 | 含义 | 交易价值 |
|---|---|---|
| `r(信号, gap)` | 信息是否传导 | ❌ **无** —— 你无法在开盘前用这个价格成交 |
| `r(信号, intra)` | 开盘后是否同向延续 | ✅ **这才是能赚的部分**（开盘买入，收盘卖出） |

### 判据

> **只有 `r(intra)` 显著，信号才是可交易因子。**
> `r(gap)` 高只说明"会跟着高开"，那是**没有交易价值的必然结果**。

---

## 辅助工具：多 horizon 复核

单看 1 日不够 —— 有些因子在更长尺度上才显现。补一轮：

```
for k in (1, 3, 5, 10, 20):
    r(信号[D], 标的从 D+1 起持有 k 日的累计收益)
```

**判据**：所有 horizon 都 ≈ 0 → 淘汰。

## 已通过的案例（假设被否决）

### 隔夜美股 → 515880

**假设**：515880 成分股是光模块/CPO，驱动是北美 AI 资本开支；美股在 A 股开盘前收盘 → 应是最强领先指标。

**检验结果**：

| 标的 | r(US, gap) | r(US, intra) |
|---|---:|---:|
| TSM | **0.453** | 0.004 |
| LITE | 0.411 | 0.024 |
| COHR | 0.398 | 0.028 |
| MRVL | 0.344 | 0.023 |
| NVDA | 0.293 | **-0.047** |
| AAOI | 0.286 | 0.051 |
| AVGO | 0.252 | 0.001 |
| 光模块组等权 | 0.401 | 0.044 |
| 新易盛 | 0.382 | 0.015 |
| 中际旭创 | 0.368 | 0.021 |

多 horizon（1/3/5/10/20 日）：**全部 ≈ 0**（-0.04 ~ 0.05）。

**判定：否决。**

### 这个否定结果的推论价值 ★

> 如果连 **COHR / LITE**（业务直接对标、时间明确领先、gap 相关性 0.4）
> 都预测不了 A 股后续走势 —— 那么
> **「用公开信息预测这个标的的日线收益」这条路基本是关的。**

并且**印证了用户的直觉**：「股票是秒级别的」。

**结论：alpha 大概率在秒级，而秒级正是数据能力和执行能力都够不到的地方。
不要在这个标的上做日内。**

## 因子分层（防止堆砌）

| 层 | 频率 | 回答 | 例 |
|---|---|---|---|
| **背景** | 季/月 | 要不要在场 | AI capex 趋势 |
| **趋势** | 日/周 | 方向 | RS、均线结构 |
| **状态** | **秒/分** | 今天能不能动手 | 龙头异动、宽度、溢价率 |
| **执行** | 分钟 | 挂什么单 | 条件单价位 |

**关键**：用户的执行能力是**分钟级**（人工 + 条件单），
所以**秒级数据不能进决策层**，只能进状态层 —— 用它去**否决或放行**已定的日线决策，
而不是产生秒级信号。

## 标的特性的判断

515880 的成分股（光模块/CPO：新易盛、中际旭创、工业富联…）是
**事件驱动 + 主题投资**，不是均值回归的票。日内 ±8% 常见。

| | 适合 | 不适合 |
|---|---|---|
| 方法 | **趋势跟踪 + 波动率定仓**（不预测，跟随） | 精细多因子择时 |
| 仓位 | 波动率倒数定仓（ATR / 已实现波动） | 固定仓位 |

**固定仓位会被 ±8% 的日波动打爆。**

## 调优闭环

```
1. 记录   信号 → 决策 → 成交 → 事后 1/5/20 日结果，全落盘
2. 归因   亏损来自 ①信号错 ②执行滑点 ③仓位过大 ④数据滞后
3. 检验   每个因素过 gap/intra + 多 horizon
4. 修改   只在证据充分时改
```

**第 1 步是前提。** 没有记录，归因无从谈起，调参就是猜。

## 交易成本提醒

- ETF 佣金通常可谈到万 1 上下，但注意**最低收费**（常有 5 元最低）
- 单笔金额小时，最低收费会吃掉大量收益 —— 小资金必须算清楚
- 条件单**触发用快照价**（几秒一档），且**触发 ≠ 成交**（跌停时挂了也卖不掉）
