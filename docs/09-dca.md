## 二、结论

1. **你的佣金结构 = 免五级别，成本问题不存在**：
   日投 1 手单笔佣金 0.1 元（≈0.06%），11 年总共 272 元。
   **每日定投可以原样执行**，频率不再是决策变量（XIRR 19.75~19.80% 全员贴平）。
2. **费率已入策略配置**：`TRADING_FEE_RATE=0.00005` / `TRADING_FEE_MIN=0.1`
   （`config.Settings`，`.env` 可覆盖；`dca.py` 另有 `--fee-rate/--fee-min`）。
   注意与回测的 `COST_PER_SIDE=0.05%` 是两套口径：前者算实账，
   后者是佣金+滑点的保守压力假设，不回改。
3. **所有择时过滤仍是噪声（±0.2pp 内）**：
   - 5月线过滤**唯一稳定变差**（-0.18pp）——牛市延迟买入 > 躲避的下跌
     （docs/08 第三次印证）。
   - 溢价>5% 暂停在你的费率下是**全场最优**（+0.02pp，免费），可作为默认规则。
4. **真正的风险不是策略，是资产**：市值最大回撤 ~30%（2022），
   任何定投变体都一样。定投解决「怎么买」，解决不了「-30% 拿不拿得住」。
5. XIRR ~19.8% 是 2015-2026 纳指长牛 + QDII 溢价摩擦后的净结果；
   起点偏乐观（2015 股灾后起投），预期应打折。
