# 20 · 当日红绿归因：今天为什么赚 / 为什么亏

> 需求（2026-09-16）：把账户**当日**的盈亏拆成可解释的来源。
> 实现：`libre_quant/attrib.py` + `GET /api/accounts/{aid}/attribution` +
> 「我的盘」页"为什么红/绿"按钮。

## 一、分解口径

对交易日 T（金额单位：元）：

```
day_pnl  = 市场项 + 日内成交项 − 当日费用
市场项   = 昨日份额 × (今收 − 昨收)
         = 美股隔夜 + 汇率 + 溢价/残差     （QDII；加法一阶近似，
                                            二阶交叉项并入残差）
```

* **美股隔夜** = 昨日市值敞口 × A 股 T 日开盘前已完成的最近美股 session
  收益（US 日期 ≤ T-1；代理映射 `US_PROXY`：159941/513100→qqq，513500→spy）。
* **汇率** = 昨日市值敞口 × USDCNH 日变动（人民币升值 → 负贡献）。
* **溢价/残差** = 市场项 − 上两项。含日内溢价变化、跟踪差、噪声——
  **故意不做日频净值配对**（docs/11 的教训：价格实时 vs 净值滞后 2 天，
  错配制造假信号）。
* **费用** = 当日买卖佣金合计；日内成交项在收盘价成交假设下为 0。

恒等式（`tests/test_attrib.py` 固化）：
1. 分项和 == 市场项（残差按差定义，恒成立）；
2. day_pnl == 市场项 − 费用；
3. 与账面口径一致：`value_T − value_{T-1} − 当日投入`（收盘成交下逐位相等，
   `test_matches_ledger_day_pnl_on_close_fills`）。

## 二、边界

* **境内 ETF / 股票**：无美股代理与汇率暴露 → 美股/汇率/残差为 null，
  市场项即全部（"今天绿 = 标的本身跌了"，不再细拆——成分股日归因需要
  PCF 日频穿透，成本高收益低，暂不做）。
* **数据缺失**：美股/汇率序列缺当日数据时该因子为 null（不发明数字）；
  长假后回退最近已知（4/15 周一用 4/12 周五的美股收益）。
* **无前日持仓**（新账户第一天）：不产生归因行。

## 三、呈现

「我的盘」每账户卡："为什么红/绿"按钮 → 今日一行式
（今日盈亏 = 市场波动（美股隔夜 · 汇率 · 溢价/残差）− 费用）+
近 10 日明细表 + 近 30 日合计。API 返回 `rows/latest/totals`，
`window` 可调（默认 30）。
