## 四、QDII 特有的新研究问题（515880 没有的）

1. **溢价率**（一等公民）：QDII 外汇额度限购时，场内价格可溢价 5%~15%。
   「溢价 >2% 禁止买入」应从 `docs/04` 的待办升级为硬规则。
   前提数据资产：**历史净值 + 场内价格 → 溢价率序列**。
2. **时间错位定价**：A 股 15:00 收盘 → 美股 21:30 开盘。当日 QDII 收益
   = 市场对今晚美股的共识预测 + 溢价变动。研究对象：
   QDII 当日收益 vs 当夜 SPY/QQQ 收益的关系（"隔夜映射"的 QDII 版，
   但对象从 alpha 变成**定价/溢价机制**）。
3. **T+0**：QDII ETF 是 T+0 交易，成本模型与 515880（T+1）不同。
4. **汇率**：人民币计价含 USD 汇率波动。暂不建模、不对冲，归因时显式标注。
5. **监管周期**：外汇额度发放/限购周期驱动溢价 regime，做归因背景知识。

## 八、附录：历史净值数据的判断标准与实测（2026-09-15）

### 8.1 判断标准（验收清单）

拿到任何净值数据源，按四条验收：

1. **覆盖完整性**：起点 ≈ 基金成立日；条数 ≈ 交易日数；`>5 天`的间隔必须能
   一一对应节假日（或募集期的周频净值），不允许出现解释不了的洞。
2. **交叉验证（用独立通路）**：与 gtfund PCF 内嵌的 `<NAV>` 对照。
   语义：清单日 T 的 NAV ≡ 东财标签 **T-1（国内）/ T-2（QDII）** 的净值，
   数值上必须**精确相等**（本次实测两个标的全中）。
3. **日期归属惯例**：必须先确定"净值标签 T 对齐的是哪个市场的哪次收盘"，
   否则溢价全算错（见 8.2 实测确证）。
4. **量级合理性**：国内 ETF 溢价应落在 ±1%；QDII 平时 <2%、
   额度限购期可达 5%~15%。超出合理区间 → 先怀疑配对错，再怀疑数据错。

### 8.2 实测结果（东财 pingzhongdata，本机验证）

| 标的 | 条数 | 起点 | 连续性 |
|---|---:|---|---|
| 513100 | 3214 | 2013-04-25 | 无异常洞（长假/募集期外无 >5 天间隔） |
| 513500 | 3010 | 2013-12-05 | 同上 |
| 515880 | 1709 | 2019-08-16 | 2019-08 为募集期周频净值（与 09-06 挂牌吻合），其后连续 |

**交叉验证**：`PCF(2026-09-11).NAV` → 515880 = 0.671 == 东财 **09-10** 值（偏移 T-1）；
513100 = 1.9873 == 东财 **09-09** 值（偏移 T-2）。数值精确相等 ✅。

**日期归属惯例（本项目的操作定义）**：

- **国内 ETF（515880）**：净值标签 T = A 股 T 收盘，T 晚公布；
  T 日决策时可确知的最新净值 = 标签 T-1。
- **QDII（513100/513500）**：净值标签 T = 美股 T 日收盘（北京时间 T+1 凌晨结束），
  **T+1 白天才公布**；T 日可确知的最新净值 = 标签 T-1（当日白天或已公布）
  ～ T-2（PCF 清单证实 T 日早间只有 T-2）。**回测保守取 T-2，另做 T-1 敏感性**。
- 因此溢价统一用 **ASOF 配对：`price[T] ÷ 最近已公布净值`**，绝不使用未来净值（无前视）。
